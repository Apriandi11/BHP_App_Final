# 📦 SIMBADA Companion — BHP DPMPTSP (macOS Edition v2.0)

Aplikasi web pendamping **Penyimpan Barang (Barang Habis Pakai / ATK)** untuk internal DPMPTSP Kota Pontianak. 
Dirancang dengan fitur:
- **Dual-Tracking** (Stok Fisik vs Saldo SPJ SIMBADA) secara paralel.
- **Antrean FIFO Multi-Batch** untuk akurasi harga satuan.
- **Kalkulator Rekonsiliasi Desimal** (Presisi 4 Desimal `DECIMAL(15,4)`).
- **Pencatatan Subsidi Silang & Kasbon Bidang**.
- **Cetak SBBK (Surat Bukti Barang Keluar)** resmi siap tanda tangan.
- **Antarmuka Desktop-Class macOS Glassmorphism** (Dilengkapi Light & Dark Mode).
